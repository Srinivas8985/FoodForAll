Project Report: FOOD FORALL

Submission Date: February 22, 2026

Project Title: FOOD FORALL

Category: Web-Based Social Impact System

1. Executive Summary

FOOD FORALL is a comprehensive ecosystem designed to bridge the gap between food surplus and food scarcity. By leveraging modern web technologies and Artificial Intelligence, the platform facilitates seamless coordination between Donors, NGOs, Volunteers, and Administrators. The recent high-impact phase introduced AI-driven Hunger Analytics using Google Gemini, a real-time Chat System, and an automated Notification framework, making it an intelligent and highly responsive platform.

2. Technology Stack

  • Frontend: React.js, Vite, Tailwind CSS, Framer Motion (Animations), Leaflet (Mapping)
  • Backend: Node.js, Express.js, MongoDB (Mongoose), Nodemailer
  • AI Integration: Google Gemini API (@google/genai)
  • Authentication: JWT (JSON Web Tokens) with Cookie-based persistence
  • Hosting: Vercel (CI/CD Deployment)

3. Key Modules & Features

🤖 AI Hunger Analytics (Powered by Gemini)

A flagship feature that transforms raw data into actionable intelligence.

  • Smart Analysis: Uses the gemini-2.5-flash model to analyze hunger reports and donation patterns.
  • Automated Insights: Generates reports for Admins identifying critical areas and recommending distribution strategies.
  • Implementation: Built using a dedicated aiService.js to securely interact with the Google Generative AI API.

💬 Real-Time Chat & Coordination

Direct communication channel for logistics and verification.

  • Feature: Secure messaging between Donors, NGOs, and Admins.
  • Smart Notifications: Integrated with the notification system to alert users of new messages instantly.
  • Purpose: Facilitates coordination of food pickups and trust building between parties.

🗺️ Hunger Heatmap & Visualization

Spatial representation of hunger needs.

  • Map View: Interactive Leaflet map showing hunger intensity scores.
  • Heatmap: Visual cues (Red/Orange/Yellow) to guide NGOs to areas with the highest unmet demand.

💰 Integrated Donation Flows

Support through both food and financial contributions.

  • Food Donation: Categorized by cooked/raw/packaged with expiry tracking.
  • Money Donation: Dedicated flow for financial support with transparency tracking.

4. Backend API & Database Design

The system follows a RESTful architecture with a secure middleware layer:

  • Security: Protected routes using auth.js middleware to verify JWT tokens and user roles.
  • CORS: Cross-Origin Resource Sharing configured for secure frontend-backend communication.
  • Schemas: Unified models for User, FoodDonation, MoneyDonation, Conversation, and Notification.

5. Results & Conclusion

The "FOOD FORALL" platform successfully demonstrates how technology can solve complex logistics in humanitarian aid. With the integration of **Generative AI**, the platform has evolved from a simple matching service into a proactive analytics system. It is now a fully functional, high-performance web application ready for real-world social impact.
